# Как читать файлы макета

Файлы `*.dc.html` — это интерактивный макет из редактора дизайна, а не продакшн-код. Используйте их как визуальный и поведенческий эталон: разметку, цвета, отступы, тексты и логику состояний. Переносить синтаксис как есть не нужно.

| Файл | Экран |
|---|---|
| `Empty.dc.html` | Потоки — список пуст |
| `Main.dc.html` | Потоки — список и выбранный поток |
| `Settings.dc.html` | Настройки |
| `Analyze.dc.html` | Анализ видеозаписей |

## Служебный синтаксис

| В макете | Значение | В React-реализации |
|---|---|---|
| `<x-dc>…</x-dc>` | корень разметки компонента | JSX компонента |
| `<helmet><style>…</style></helmet>` | глобальные стили и шрифты страницы | глобальный CSS / `tokens.css` |
| `{{ name }}` | подстановка значения из `renderVals()` | `{name}` |
| `style="{{ s.cardStyle }}"` | стиль, вычисленный в JS по состоянию | условные классы / `style` |
| `<sc-for list="{{items}}" as="it">` | цикл | `items.map(it => …)` |
| `<sc-if value="{{cond}}">` | условный показ | `{cond && …}` |
| `onClick="{{ handler }}"` | обработчик | `onClick={handler}` |
| `hint-placeholder-*` | подсказки редактору при загрузке | игнорировать |
| `<script src="./support.js">` | рантайм редактора | игнорировать |
| `class Component extends DCLogic` | состояние (`this.state`) и вычисление значений (`renderVals()`) | хуки `useState` / `useMemo` |
| `data-props='{…}'` | ручки редактора (акцентный цвет и т. п.) | игнорировать |
| `<a href="Settings.dc.html">` | переход между экранами макета | маршрут из `SPEC.md` §2 |

## Что в макете ненастоящее

- Все данные (`STREAMS`, `CAMS`, `FILES`, числа, время, адреса, `[@контакт]`) — демо-константы в `<script>`. В реализации данные приходят из API (`API.md`).
- `[ КАДР ВИДЕОПОТОКА ]` — заглушка вместо живого видео.
- Прозрачная кнопка на весь экран под открытым меню — упрощённый click-outside. В реализации нужен нормальный click-outside и Esc.
- Блоки `<style>` с `:hover` — упрощение. Состояния наведения и фокуса берите из `tokens.css`.
