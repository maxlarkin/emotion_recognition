## (b) Updated parameter rows

| Parameter | Minimum | Recommended | Evidence |
|---|---|---|---|
| Face size (pixels) | Head region >= 36x48 px (unreliable below this). Face crop >= 48x48 is a common FER input (unverified this run). | Head region >= 72x96 px (no measurable loss above this, per Tian 2004 as cited in F7). IED >= 90 px if aiming at ICAO-grade capture (F1). | F7, F1, F3 |
| Head pose | Yaw/pitch <= 30 deg for full accuracy. Up to 45 deg is still usable with a pose-robust model: loss is about 2 points on RAF-DB and 6-9 points on FERPlus/AffectNet. | <= +/-15-20 deg yaw as an operating target (engineering judgement, not directly evidenced). ICAO frontal is +/-5 deg (F2), which is far stricter than FER needs. | F4, F5, F2 |
| Video compression | Above about 0.1 bpp (learned codec) or QP < 24 (H.26x on small faces), losses are negligible. | "Good to excellent visual quality" range. Avoid aggressive QP (>30) on the face region. A specific JPEG quality number could not be quantified. | F6, F7 |
| Frame rate / frames per clip | 8-16 sampled frames per clip. Gains plateau above a model-dependent threshold. | 16 frames uniformly sampled per clip (the common DFEW/FERV39k practice). **No direct fps (30/15/10/5) ablation was found.** | F10 |
| Audio SNR | >= 10 dB (about 2-3 point UAR loss vs clean with SSL models) | >= 20 dB (an extrapolation; 20 dB was not tested in F8). At 0 dB, expect a 6-9 point loss. | F8, F9 |
| Reverberation | not found | not found | none |
| Segment / utterance length | not found this run | not found | none |
| Acted-dataset accuracy (~95-100%) | Confirmed about 96% on RAVDESS audio-visual, under a random 80/20 split that is not actor-independent. CK+, RESD and JAFFE were not verified. | Treat about 95-100% as protocol-inflated (random splits, acted data). Do not use it as a deployment target. | F11, F12 |
